# 試験仕様書兼結果書

文書ID：TST-01／版：1.0／作成日：2026-10-29／状態：レビュー用・既存結果の事後整理。

本書作成時にAWSを再起動して再試験したものではない。2026-10-26〜29の公開済み記録を照合した結果を記載する。「確認済み」は記載した範囲の実績を指し、設計上の全条件・性能・セキュリティを保証しない。要件との対応は[索引](README.md)、期待仕様は[詳細設計書](detailed-design.md)を参照。

## 試験の前提・判定方法

- 対象段階の環境・認証・依存資源を用意し、正常時の応答と元データを確認してから試験する。
- 追加資源は元資源と名前・ID・マウント先を区別する。復元済み領域へmkfsを実行せず、元DBへリストアを上書きしない。
- 障害演習は復旧処理を組み込む。定期ルールの変更は試験後に無効へ戻し、失敗時も放置しない。
- APIキー・購読先・認証情報を証跡へ掲載しない。コード、HTTP本文、SQL、通知、ジョブ状態を目的に応じて組み合わせる。
- 期待値と結果が一致しても、範囲外の要件まで合格としない。未実施は末尾U01〜U08へ分ける。
