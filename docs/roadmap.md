# 段階的な発展計画

本リポジトリの完了実績はDay 1です。以下のDay 2〜4は計画であり、コード・画面・実行履歴を取得するまで完了扱いにしません。

| 段階 | 状態 | 予定する内容 | 完了判定 |
|---|---|---|---|
| Day 1 | 完了 | RHEL / Apache / Tomcat / PostgreSQL / EBS / EFS / S3 / CloudWatch | 再起動後の動作・実ログ・停止・スナップショット |
| Day 2 | 未実施 | Aurora移行、ALB/NLB、AWS Backup | 移行後のDB接続、正常/異常時挙動、復元結果 |
| Day 3 | 未実施 | ECR / ECS Fargate / CI/CD / API Gateway | ビルド・配備・API呼出しの実行結果 |
| Day 4 | 未実施 | SNS / Step Functions / EventBridge / 運用演習 | 成功/失敗通知、障害復旧、削除と費用記録 |

## 目指すストーリー

Linux上に同居するWeb/DBから始め、DBをマネージド化し、アプリをコンテナ化し、配備と運用を自動化します。サービス数だけでなく、それぞれを導入する理由と、導入前後で変わる運用責任を説明します。

新しい段階を追加する際は、実施日、構成差分、検証結果、費用・削除状態を記録します。4日間の予定を完了実績のように記載しません。
