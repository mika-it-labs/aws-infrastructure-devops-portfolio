# 公開証跡

Day 1のAWS API応答とSSM経由のコマンド結果から、提出に必要なファイルを選択しました。ここにある内容はサンプルとして捏造した実行結果ではありません。

| ファイル | 収集元・意味 |
|---|---|
| verification.txt / verification.json | OS更新後の再起動を経て実行したSSM検証結果 |
| application.html | EC2ロールでS3へ保存し、ローカルへ回収したHTTP応答 |
| log-groups.json | 保持7日、各グループの実イベント存在確認。全件数ではない |
| metrics.json | CloudWatch list-metricsに出現したOS指標。負荷試験結果ではない |
| alarms.json | アラーム設定と収集時点の状態 |
| final-state.json | 2026-10-26終了時のEC2停止・Standard復帰・スナップショット完了 |
| account-cost-today.json | 当日・アカウント全体の推計値。演習の確定金額ではない |

## 公開のための加工

アカウントID、ARN中のアカウント部分、リソースID、コマンドID、EC2/EFSの実IP、ボリュームのSERIALをプレースホルダーへ置換しました。設定値・メトリクス名・成否・日時は保持しています。CIDR設計とloopbackアドレスは説明のため残しています。

元のテキストにあるlsblkの罫線は収集時に文字化けしており、公開版ではその部分だけASCIIのハイフンへ置換しています。表示の整形であり、値の補完や検証結果の改変は行っていません。

未加工の台帳、個別アカウントのクレジット情報、認証情報、秘密鍵、DBパスワード、ブラウザーのセッション情報は含めていません。原本から公開版を作った後、識別子と秘密情報のパターン、ファイル間リンク、JSONとPowerShellの構文を検査します。

保存済みのブラウザー画像は収録していません。assetsの構成図は説明用の図であり、コンソール画面の証跡ではありません。
